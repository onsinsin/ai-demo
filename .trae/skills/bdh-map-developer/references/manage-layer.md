# 创建图层列表

## 1 输入输出

### 输入

用户加载的底图（或资源）图层信息。

### 输出

生成的图层列表组件代码

## 2 执行流程

### 2.1 从用户加载的图层信息中提取图层列表
从图层查找的结果中提取图层id和label，作为图层列表。

### 2.2 根据图层列表生成图层列表界面
生成图层列表界面，在地图左侧显示，每个图层项包含图层名称和勾选框。

### 2.3 图层列表勾选控制图层显示
用户在图层列表中勾选图层，地图上对应的图层会显示；取消勾选，图层会隐藏。
控制地图上图层显示的步骤如下：
#### 2.3.1 从用户勾选的图层列表中提取勾选的图层id，再根据列表的图层id关联mapbox的layerId
- 列表上的图层id可能对应多个mapbox layerId，关联关系需要从图层加载接口返回的bizGisLayerRelation中获取。
#### 2.3.2 调用mapbox-gl地图的api，根据mapbox layerId控制图层显示
- 勾选图层，调用 map.setLayoutProperty(layerId,"visibility", "visible") 显示图层；
- 取消勾选图层，调用 map.setLayoutProperty(layerId,"visibility", "none") 隐藏图层。

## 3 执行规则
- 图层默认都是显示状态
- 要求底图图层、资源图层同时在列表中展示，且用不同的图标区分。
