# 6. 给 AI Agent 的生成指南

当 AI 需要生成 LowcodeEngine 页面时，请遵循以下步骤：

1. **确定根结构**: 必须包含 `version` 和 `componentTree`。
2. **构建组件树**: 从 `Page` 开始，嵌套子组件，确保 `componentName` 准确。
3. **声明组件映射**: 在 `componentsMap` 中列出所有非内置组件的来源。
4. **定义状态与数据**: 在 `state` 和 `dataSource` 中预定义所需数据和状态。
5. **编写逻辑**: 将交互逻辑写入 `methods`，生命周期写入 `lifeCycles`。
6. **绑定事件与条件**: 在组件节点中使用 `events`、`condition`、`loop` 实现动态行为。
7. **补充元数据**: 填充 `config` 和 `meta` 以便管理和追踪。

**注意**:

- 所有 JS 逻辑必须以**字符串形式**存储在 `methods` 和 `lifeCycles` 中。
- 数据绑定使用 `${...}` 语法，如 `${state.count}` 或 `${dataSource.api.data}`。
- `componentTree` 是一个数组，支持多根节点（例如同时定义 Page 和 Dialog）。
